# GlowNails

Personal nail studio site for **GlowNails** in Skopje.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Customize

Edit `src/data.ts` for services, gallery images, and pricing.
